# homelab
Its a lab, but at home.

Run `make` for the list of actions. Each project has its own Makefile; from the repo root,
run a project's target as `make <project>/<target>` (for example `make fire-tv/status`), or
`make help-all` to see every project's targets. Run `make hooks` once per clone to turn on
the pre-commit secret scan.
